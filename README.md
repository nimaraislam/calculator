# Kalkylator

Ett enkelt Python-projekt som demonstrerar Continuous Integration med GitHub Actions.

## Köra testerna

pip install -r requirements.txt
pytest tester/ -v

#### Första commit

Nu gör vi vår första *commit* - det vill säga vi sparar ett snapshot av koden i versionshistoriken:

git add .
git commit -m "Initialt projekt: kalkylator med tester"
